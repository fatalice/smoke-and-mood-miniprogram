# 戒烟树洞小程序 · 产品说明文档

> 文档版本：v1.0 · 对应实现：`戒烟树洞.html`（双功能单页 demo）
> 用途：供开发 Agent 阅读后直接实现/还原为微信小程序。本文描述的是**目标产品需求 + 当前 demo 已验证的实现约定**，两者一致，可直接作为开发依据。

---

## 1. 产品概述

一款帮助用户记录吸烟、逐步控量的戒烟辅助小程序，同时内置匿名「树洞」留言社区，让用户在戒烟路上有人倾诉、互相支持。

- **产品定位**：轻量、私密、温和陪伴的戒烟工具
- **目标用户**：想记录吸烟量、逐步减少吸烟、正在戒烟或寻求情绪支持的人群
- **双核心功能**：
  1. **记录戒烟**：每日设上限，记录每一支烟，实时看「总量 / 已抽 / 剩余」，超限提醒
  2. **树洞留言**：完全匿名发布心事，可被「共鸣」点赞，按情绪标签筛选浏览
- **形态**：两个功能页 + 底部 Tab 栏切换（记录戒烟 / 树洞留言）

## 2. 页面结构

```
小程序
├── Tab 1：记录戒烟（默认首页）
│   ├── 顶栏：日期 + 副标题（与昨日对比） + 连续达标天数徽章 + 设置额度入口
│   ├── Hero 卡：今日吸烟额度
│   │   ├── 进度环（SVG）：中心大数字 = 剩余额度；超限显示 "+N" 并变红
│   │   ├── 三格统计：今日总量 / 已抽 / 剩余
│   │   ├── 状态行（三态文案，见 4.4）
│   │   └── 副信息：距上次吸烟时长
│   ├── 操作区：「记录一支」主按钮 + 「撤销上一支」次按钮
│   ├── 最近 7 天：柱状图（ECharts），今日柱高亮
│   └── 今日记录：时间倒序列表（时间 + 诱因标签 + 删除）
├── Tab 2：树洞留言
│   ├── 顶栏：日期 + 「匿名模式」徽章 + 关于树洞入口
│   ├── Hero 卡：树洞标语 + 三格统计（今日留言 / 共鸣 / 累计留言）
│   ├── 操作区：「写一条留言」主按钮
│   ├── 筛选条：全部 / 心事 / 吐槽 / 求助 / 戒烟 / 生活（横滑）
│   └── 留言流：卡片列表（标签 + 时间 + 正文 + 共鸣按钮）
└── 底部 Tab 栏：记录戒烟 / 树洞留言
```

弹层（Bottom Sheet）：记一支（选诱因）、设置额度（步进器）、写留言（输入+标签）、关于树洞（规则说明）。共享遮罩与 Toast。

## 3. 功能需求明细

### 3.1 记录戒烟页

| 功能 | 需求描述 |
| --- | --- |
| 今日额度 | 默认 10 根/天，可随时修改，范围 1–30 根；额度跨日保留（用户设定不因日期重置） |
| 记录一支 | 点击弹出「记下这一支」弹层 → 选择诱因（压力/社交/无聊/饭后/工作/其他，单选）→ 确认后已抽 +1 |
| 进度环 | 已抽/总量 进度动画；剩余额度为中心大数字；剩余=0 环满；超限时环变红、中心显示 "+超出数" |
| 三态文案 | ① 剩余>0：「今日还剩 N 根，悠着点」（绿调）② 剩余=0：「今日额度已用完，忍一忍，明天再来」（琥珀调）③ 超限：「已超出限额 N 根，身体要紧」（红调） |
| 撤销 | 撤销最后一条记录（无记录时 Toast 提示） |
| 删除记录 | 单条删除需二次确认（点删除 → 按钮变「确认删除」，2.2s 内再点才生效） |
| 距上次吸烟 | 取最后一条记录时间，格式：X 分钟前 / X 小时 Y 分钟前 / X 天 Y 小时前 / 刚刚 |
| 连续达标天数 | 从今天往前数，每日已抽 ≤ 当日额度的连续天数；显示「连续 N 天」，无则「无连续达标」 |
| 昨日对比 | 副标题显示与昨日已抽数的差：「今天已坚持 · 比昨天少 N 根」/「比昨天多 N 根，注意节奏」/「与昨天持平，稳住节奏」 |
| 最近 7 天图 | 每日根数柱状图，今天高亮琥珀色；副标题显示近 7 天日均 |
| 每日重置 | 跨日后自动重置「今日已抽」和「今日记录」；近 7 天历史保留；额度保留 |

### 3.2 树洞留言页

| 功能 | 需求描述 |
| --- | --- |
| 写留言 | 弹出「写一条留言」弹层：200 字上限（实时计数）、单选标签（心事/吐槽/求助/戒烟/生活）、内容为空时发布按钮置灰 |
| 匿名 | 全程无昵称、头像、位置；「匿名模式」徽章 + 关于树洞弹层说明规则（保留 30 天、过滤违规、可被共鸣） |
| 留言流 | 按时间倒序；时间格式：今天 HH:MM / 昨天 HH:MM / M/D HH:MM |
| 长文展开 | 正文超 3 行折叠，显示「展开/收起」 |
| 共鸣 | 每条留言可点赞/取消（心形图标切换填充色 + 弹跳动效），计数 ±1 |
| 筛选 | 全部 + 5 个标签横向滑动筛选；分类无内容时展示空态引导 |
| 统计 | 今日留言数 / 总共鸣数 / 累计留言数，实时更新 |

### 3.3 通用

- 所有操作有反馈：Toast（顶部胶囊，约 2.2s 自动消失）
- 弹层：底部上滑（约 0.32s），点遮罩关闭
- Tab 切换：树洞页**懒加载**（首次切到才初始化）；切回戒烟页时图表自动 `resize()`

## 4. 数据模型（localStorage）

### 4.1 戒烟页 `key: smoke_tracker_v1`

```js
{
  limit: 10,                    // 今日额度（1–30）
  counts: { "2026-10-04": 6 },  // 每日已抽数，key 为日期 YYYY-MM-DD
  records: [ { t: 1730000000000, reason: "压力" } ],  // 仅存当天的记录
  lastDate: "2026-10-10"        // 上次活跃日期，用于跨日重置
}
```

- `t`：时间戳（ms）；`reason`：诱因，枚举「压力/社交/无聊/饭后/工作/其他」
- 跨日重置：`lastDate ≠ 今天` 时 → `records = []`、`counts[今天] = 0`、`lastDate = 今天`
- 清理：只保留最近 15 天 `counts`，图表取最近 7 天

### 4.2 树洞页 `key: tree_hole_v1`

```js
{
  messages: [
    { id: 1, tag: "心事", text: "…", t: 1730000000000, likes: 12 }
  ],
  liked: { "1": true }   // 当前用户共鸣过的 message id
}
```

- `tag`：枚举「心事/吐槽/求助/戒烟/生活」；`likes`：共鸣数；`liked`：本地共鸣状态（可取消）
- 留言无删除功能（匿名产品语义，30 天后自动消失由后端实现）

- 阴影：主按钮 `0 12px 26px -10px rgba(240,140,58,.6)`；进度环光晕 `drop-shadow(0 0 7px rgba(255,180,84,.45))`

## 6. 技术约束（重要）

- **单文件自包含**：一个 `.html`，CSS 内联 `<style>`、JS 内联 `<script>`，原生 JS，无构建工具、无框架
- **图表**：ECharts 5（`https://cdn.jsdelivr.net/npm/echarts@5.5.0/dist/echarts.min.js`）
- **字体**：`https://miaoda.feishu.cn/fonts/css2?family=Noto+Sans+SC:wght@400;500;700;900&display=swap`
- **无后端**：数据存 localStorage；真实上线需后端接口（见 §8）
- **无障碍/移动端**：可点击目标 ≥ 44×44px；输入框字号 ≥ 16px（防 iOS 聚焦缩放）；支持 `prefers-reduced-motion`
- **安全**：用户输入（留言正文）渲染前必须做 HTML 转义；不得引入 OWASP 高危模式
- **状态管理**：普通对象 + 重渲染函数（`renderSmoke()` / `renderFeed()`），不做响应式框架
- 桌面端 `_shots/` 为自检截图输出目录，不属于交付产物

## 8. 真实小程序落地建议（超出当前 demo 范围）

1. **导航**：改用微信原生 `tabBar`（记录戒烟 / 树洞留言），每页独立，天然免性能问题
2. **后端**：需要用户体系（openid）、留言表（匿名 id + 内容 + 标签 + 共鸣数 + 创建时间，30 天自动清理）、戒烟记录表（日期 + 数量 + 诱因）
3. **内容安全**：留言发布走微信内容安全接口（`security.msgSecCheck`）过滤违规内容
4. **数据同步**：localStorage 仅作 demo；正式版以服务端数据为准，本地做缓存
5. **提醒**：可扩展「今日额度提醒」「连续达标勋章」「戒烟省钱统计」等激励模块
